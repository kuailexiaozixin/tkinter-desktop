# Prerequisite Skills
* Graphical User Interface (GUI) design (or have an app to mimic or have mockups from a designer)
* Python Programming (or be on a team with a programmer)
* File Management
* Use of the command-line, terminal, or shell.
* Program Installation (or have someone to do it for you)

# Desktop or Laptop Computer
* with the Windows, macOS or Linux operating system
* a Monitor
* a Keyboard
* a Mouse, Trackpad, or the functional equivalent
* 1 Megabyte of free storage space on your hard drive (HD), Solid State Drive (SSD), or the functional equivalent
* 4+ Megabytes of RAM
* [Python](https://www.python.org) v3.9 or greater
* [pip](https://pypi.org/project/pip/), normally it comes with Python
* A text editor
