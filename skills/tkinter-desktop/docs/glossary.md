# 术语解释（面向零基础用户）

| 术语 | 大白话 |
| ---- | ------ |
| Tkinter | Python 自带的"画窗口"工具箱，不用额外安装 |
| ttk | Tkinter 的现代款控件（按钮、输入框长得更像系统原生） |
| 控件 (widget) | 界面上的零件：按钮、输入框、表格、下拉框 |
| mainloop | 程序的"心跳"：窗口能响应点击就是它在转 |
| Treeview | 那个带表头的表格控件 |
| Notebook | 标签页容器（像浏览器的多个标签） |
| grid | 摆控件的方法：把界面想成表格，控件放进第几行第几列 |
| MVC | 代码分三层：管数据的（Model）、管界面的（View）、牵线的（Controller） |
| SQLite | 一个文件就是一个数据库，程序自带，不用装数据库软件 |
| venv | 项目专属的 Python 小环境，避免把电脑环境搞乱 |
| PyInstaller | 把 Python 程序压成一个 EXE 的打包机 |
| --windowed | 打包选项：双击 EXE 不带黑色命令行窗口 |
| DPI 感知 | 高分辨率屏幕上不糊字的开关 |
| 冒烟测试 | 交付前最基本的"能不能跑起来"检查 |
| 无头冒烟 | 不弹窗口、由脚本自动检查界面零件齐不齐 |

## 快速流程一览

需求澄清 → 架构设计 → 项目骨架 → 数据层 → 界面 → 接线 → 验证 → 打包交付。
详细执行清单见 SKILL.md「完整工作流」。
