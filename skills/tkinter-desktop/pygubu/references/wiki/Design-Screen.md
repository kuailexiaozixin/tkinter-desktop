The design interface is composed of the following sections:

## 1 - Components Palette

This section shows the tkinter widgets available to use.

### Container widgets

These are the only widgets permitted as root elements of the Project Tree. You need to add one of these to continue adding widgets as children of the container widget.

### Control & Display widgets

These are the basic widgets included in tkinter.

### Pygubu Helpers

These are combinations of standard widgets that implement popular UI design patterns.


### Pygubu Widgets

These are custom widgets used to build the pygubu main window and are available to use.


## 2 - Project Tree

Shows the widgets included in the project as a tree hierarchy.

### Adding a widget

To add a widget to the tree, select the widget that will be the new widget's parent and click the icon of the new widget on the Components Panel.

To add a new top-level container, make sure that no item is selected in the tree, and click on the container icon.

The columns displayed on the tree are the following:

**ID**: the unique widget identifier. When a widget is added to the tree, an autogenerated identifier is asigned. When you manually change it, this widget becomes a "named" widget. This column will show the identifier and class in the form "{identifier}:{classname}". If the widget has an autogenerated ID, it will show the class name only.

**R**: The widget's positional row number in its parent container.

**C**: The widget's positional column number in its parent container.

Atop the tree, use the filter to search for a specific widget identifier or class name.

### Moving a widget

Select the item you want to move and use the options from the menu "Edit > Widget Tree." The row and column numbers take precedence when your application runs with the grid layout.

## 3 - Properties Panel

Use this to alter the properties of the currently selected widget in the Project Tree.

It has three sections:

**Appearance**: display properties

**Layout**: layout manager choice and position with the parental container

**Bindings**: if possible, a call back function


## 4 - Preview Panel

See a preview of all top-level widgets in the Project Tree.

The blue lines and tags only appear in the preview. Thin blue lines mark the perimeter of each container. A lower-right blue displays the container's unique identifier.
Dragging the blue identifier will resize some containers. This is useful to test how the layout will behave when the window is resized.
