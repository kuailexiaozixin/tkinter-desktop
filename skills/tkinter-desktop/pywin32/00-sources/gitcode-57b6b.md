## 内容范围说明

该文档聚焦于以下三个核心模块（与 tkinter 桌面开发的原生 Win32 集成场景相关）：

- **win32gui** — Windows 窗口管理：窗口创建、查找、枚举、消息与事件处理、子类化等 GUI 相关能力。
- **win32api** — 底层 Win32 API 封装：进程/线程管理、注册表操作（RegOpenKey/RegSetValue 等）、系统信息、消息框等。
- **win32con** — Windows 常量定义：各类窗口样式、消息码、键值等，与 win32gui/win32api 配合使用的常量集合。
